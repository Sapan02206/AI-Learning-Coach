# 5-Minute Demo Checklist

## 🎯 Pre-Demo (2 minutes before)

### Setup
- [ ] Clear localStorage: `localStorage.clear()` in console
- [ ] Refresh page: `Ctrl+R` or `Cmd+R`
- [ ] Server running: http://localhost:5175/
- [ ] Browser window: Full screen or large enough
- [ ] Close unnecessary tabs
- [ ] Disable notifications

### Test Run
- [ ] Generate a plan (takes 5 seconds)
- [ ] Start one session
- [ ] Verify trust score visible
- [ ] Check credibility panel shows
- [ ] Confirm no console errors

---

## 🎬 Demo Flow (5 minutes)

### 1. Introduction (30 sec)
**Say:** "This is an AI Learning Consistency Coach that verifies genuine learning through behavioral signals."

**Show:** Landing page with form

---

### 2. Plan Generation (30 sec)
**Do:**
- [ ] Fill form:
  - Subject: "Data Structures"
  - Deadline: 7 days from today
  - Daily Minutes: 60
  - Intensity: Medium
- [ ] Click "Generate Study Plan"

**Say:** "Instant AI-powered plan generation—no waiting."

**Point out:**
- [ ] Dashboard appears immediately
- [ ] Tasks are broken down
- [ ] Credibility panel at 100%

---

### 3. Show Credibility Panel (45 sec)
**Point to:**
- [ ] Large trust score (100%)
- [ ] Color-coded panel (green)
- [ ] Risk level: Low
- [ ] Engagement: Medium

**Say:** "This behavioral authenticity engine starts trusting you, but adapts based on your actual behavior."

---

### 4. Good Behavior Demo (1 min)
**Do:**
- [ ] Click "Start" on first task
- [ ] Click around the session area (5-10 times)
- [ ] Type in notes textarea
- [ ] Check off subtasks
- [ ] Wait 30-60 seconds
- [ ] Click "Stop"

**Say:** "Watch the interaction counter increase. The system tracks genuine engagement."

**Do:**
- [ ] Fill validation form:
  - Topics: "Binary search trees"
  - Time: Accurate estimate
  - Reflection: 40+ characters
- [ ] Click "Submit & Analyze"
- [ ] Wait for "Analyzing..." (2 seconds)

**Point out:**
- [ ] Session summary appears
- [ ] Focus score shown
- [ ] Trust score increased
- [ ] Message: "🔥 Strong consistency detected!"
- [ ] Panel stays green

**Say:** "Genuine effort is rewarded with higher trust scores."

---

### 5. Bad Behavior Demo (1 min)
**Do:**
- [ ] Start another session
- [ ] Immediately click "Stop" (within 5 seconds)

**Point out:**
- [ ] Alert appears: "Too fast!"
- [ ] Trust score drops
- [ ] Task not completed

**Say:** "You can't game the system—it enforces minimum time requirements."

**Do:**
- [ ] Start session again
- [ ] Wait minimum time (30% of target)
- [ ] Don't interact much (0-2 clicks)
- [ ] Switch to another tab and back
- [ ] Stop timer

**Point out:**
- [ ] "Tab switched 1x" warning
- [ ] Low interaction count

**Do:**
- [ ] Fill validation poorly:
  - Topics: "stuff" (too short)
  - Time: Way off estimate
  - Reflection: "ok" (too short)
- [ ] Submit

**Point out:**
- [ ] Trust score drops visibly
- [ ] Message: "⚠️ Low engagement detected"
- [ ] Panel turns yellow/red
- [ ] Validation warnings shown

**Say:** "The system detects low engagement and adjusts trust accordingly."

---

### 6. Show Anti-Cheat Features (45 sec)
**Point to:**
- [ ] Progressive unlocking (try clicking subtask 3)
- [ ] Inactivity detection (explain 2-min threshold)
- [ ] Presence check (explain random popup)
- [ ] Pattern detection (explain 3-session analysis)

**Say:** "Multiple anti-cheat layers ensure genuine learning: presence checks, inactivity detection, pattern analysis, and progressive unlocking."

---

### 7. Show Visual Analytics (45 sec)
**Scroll down to:**
- [ ] Consistency Heatmap

**Point out:**
- [ ] Color-coded calendar
- [ ] Green = excellent, yellow = partial, red = missed
- [ ] Hover to see details

**Point to:**
- [ ] Best Study Time (if available)
- [ ] Streak Quality
- [ ] Consistency Trend
- [ ] Last Session snapshot

**Say:** "Visual analytics make patterns instantly clear. The system learns when you perform best and tracks quality over time."

---

### 8. Closing (30 sec)
**Say:** "This system combines AI planning with behavioral intelligence. It doesn't just generate plans—it verifies genuine learning through multi-signal tracking and adapts dynamically."

**Highlight:**
- [ ] Can't be faked (enforcement)
- [ ] Adapts to behavior (intelligence)
- [ ] Visual feedback (clarity)
- [ ] Professional polish (demo-ready)

## 💡 If Asked Questions

### "How does it detect fake behavior?"
**Answer:** "Multi-signal tracking: time quality, interaction patterns, tab switching, reflection depth, presence checks, inactivity detection, and pattern analysis across sessions."

### "Can users game the system?"
**Answer:** "No. We enforce minimum time (30%), require meaningful reflections (30+ chars), detect instant completions, track tab switches, and analyze patterns across multiple sessions."

### "What makes this different?"
**Answer:** "We don't just plan—we verify. Most tools trust users blindly. We estimate learning authenticity using behavioral signals and adapt plans dynamically."

### "Is this scalable?"
**Answer:** "Absolutely. Lightweight rule-based logic, localStorage for now but easily integrates with backend. Applicable to corporate training, bootcamps, certification programs."

### "What's the tech stack?"
**Answer:** "React 18, Vite, date-fns, localStorage. Clean, modular architecture. All behavioral logic is client-side for instant response."
